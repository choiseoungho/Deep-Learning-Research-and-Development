단체 구매 문의결제 · 환불 규정

정품 보호

문제와 해설이 바뀐 채로 돌아다니지 않도록, 모든 배포본에 RSA 전자서명을 적용했습니다.

  • 실행할 때마다 서명 확인

    프로그램은 문제 · 해설 · 실행 파일의 서명을 공개키로 확인한 뒤에만 열립니다.

  • 바꾸면 열리지 않음

    파일을 한 글자라도 고치면 서명이 맞지 않아 실행을 막습니다. 원본 ZIP을 다시 풀면 정상으로 돌아옵니다.

  • 수정은 키를 가진 제작자만

    문제를 고친 새 판은 제작자의 개인키와 키값이 있어야만 서명할 수 있습니다.

구매 절차

유료 강좌와 같은 방식으로 신청하고 계좌이체로 결제합니다.

  1. 구매 신청

    원하는 프로그램의 구매 신청을 누르고 이름과 이메일을 적습니다.

  2. 입금

    바로 받는 입금 안내 메일의 계좌로 3일 안에 입금합니다.

  3. 링크 수령

    입금이 확인되면 다운로드 링크를 이메일로 보내 드립니다.

  4. 설치 · 학습

    ZIP을 새 폴더에 풀고 안내 파일대로 실행합니다. 학습 기록은 내 PC에 저장됩니다.

환불 기준

  • 다운로드 링크를 받기 전: 언제든 취소할 수 있으며 전액 환불합니다.
  • 링크를 받은 후: 받는 즉시 전체 내용을 이용할 수 있는 디지털 콘텐츠라 단순 변심 환불은 제한됩니다.
  • 실행되지 않거나 안내와 다를 때: 정상 파일을 다시 보내 드리고, 해결되지 않으면 전액 환불합니다.

이용 조건

  • 구매한 본인의 학습용입니다. 파일 · 문항 · 해설의 복제, 공유, 게시, 재판매를 금지합니다.
  • 자체 제작 교육용 예상문제로, 국가시험 기출이나 공식 해설이 아닙니다.
  • 교수자 검수 전 단계입니다. 실제 진료 · 간호 · 처치는 최신 지침과 기관 기준을 따르세요.

자주 묻는 질문

문제는 국가시험 기출인가요?

아닙니다. 모든 문항과 해설은 딥러닝 연구개발이 자체 제작한 교육용 예상문제입니다. 국가시험 기출 원문이나 공식 해설, 외부 문제은행은 넣지 않았습니다. 기출은 국시원 누리집에서 확인하세요.

교수자 검수를 마친 문항인가요?

AI 보조로 작성하고 정답 · 해설의 근거를 점검했지만, 교수자 검수를 마친 단계는 아닙니다. 실제 국가시험 난이도와 같다고 보장하지 않으며, 진료 · 간호 · 처치는 최신 지침과 기관 기준을 따라야 합니다.

어떻게 받나요?

구매 신청 후 입금이 확인되면 이메일로 다운로드 링크를 보내 드립니다. ZIP 파일을 새 폴더에 압축 해제한 뒤 안내 파일에 따라 실행합니다.

여러 대의 PC에서 써도 되나요?

구매한 본인이 학습용으로 쓰는 PC라면 설치할 수 있습니다. 다른 사람과 파일을 나누거나 게시 · 판매하는 것은 금지됩니다. 학과 · 스터디 단위로 쓰려면 단체 구매를 이용하세요.

파일을 고치면 어떻게 되나요?

배포본은 RSA 전자서명으로 보호됩니다. 문제 · 해설 · 프로그램 파일을 하나라도 바꾸면 서명이 맞지 않아 열리지 않습니다. 받은 ZIP을 새 폴더에 다시 풀면 바로 정상적으로 쓸 수 있습니다.

Mac에서도 되나요?

한의대생 교육판과 간호학 교육판의 문제풀이 화면은 Chrome · Edge 브라우저만 있으면 Mac에서도 열립니다. 의대생 교육판, 수의 교육 프로그램, 가상환자 시뮬레이션은 Windows 전용입니다.
